# Motion-PhotoTool · 图片批量分组打包工具

移动端（含 Pad）与 PC 通用的**纯前端**图片批量处理工具：统一改尺寸 · 自定义不等量分组 · 自动重命名 · 按组压缩打包下载。

> 🔒 全部处理在浏览器本地完成，图片不会上传到任何服务器。

## 在线使用

部署 GitHub Pages 后即可直接访问（见下方「启用在线访问」）。也可下载 `index.html` + `jszip.min.js` 两文件，双击本地打开使用，无需联网。

## 功能

| 步骤 | 功能 | 说明 |
|---|---|---|
| 1 | 上传图片 / 文件夹 | 支持选择图片、选择文件夹、拖拽上传；自动按文件名排序；缩略图可拖拽或用 ◀ ▶ 手动微调顺序 |
| 2 | 统一尺寸调整 | 预设 **1280×720**、**960×540**（16:9），支持自定义宽高；裁剪方式：填满裁切 / 留白补边 / 拉伸；输出 JPG / PNG / 原格式；JPG 质量可调 |
| 3 | 自定义分组 | 输入 `9,8,11,12,11` 即按数量依次切分为数量不等的多组；总数不足时剩余图片并入最后一组 |
| 4 | 分组自由命名 | 每组独立命名，随时修改 |
| 5 | 重命名规则 | 新名 = 名称模板 + 连接符 + 序号；序号可设起始值、补零位数、**仅组内排序** 或 **全部图片连续排序**；每组实时预览「原名 → 新名」 |
| 6 | 打包命名 | 自动生成 `组名 + 起始序号-结束序号 + P`，例如 `【20261028】张艺兴1-9P.zip` |
| 7 | 按组打包下载 | 逐组生成 ZIP 并下载，可选包内是否套一层同名文件夹 |

### 命名示例

组名 `【20261028】张艺兴`，序号从 1 开始、仅组内排序：

```
原名                          →  新名
IMG_2031.jpg                  →  【20261028】张艺兴-1.jpg
IMG_2032.jpg                  →  【20261028】张艺兴-2.jpg
...
打包名： 【20261028】张艺兴1-9P.zip
```

## 关于压缩格式

仅提供 **ZIP**。RAR 为专有压缩算法，浏览器端无法生成；ZIP 可被所有设备与网盘直接解压，效果等同。

## 本地运行

```bash
git clone https://github.com/Mlinkr/Motion-PhotoTool.git
cd Motion-PhotoTool
# 方式一：直接双击 index.html
# 方式二：起本地服务
python3 -m http.server 8000
```

## 技术栈

原生 HTML / CSS / JavaScript，无构建步骤；压缩使用 [JSZip](https://stuk.github.io/jszip/)；图片缩放基于 Canvas 与 `createImageBitmap`。
